# Правила перевода

Русский язык является основным языком этой документации. Английская версия
поддерживается для меньшей части пользователей и должна следовать за русской
документацией, но не блокировать обновления русской версии.

## Источник истины

- Новые страницы и правки сначала вносятся в русскую версию.
- Русские страницы считаются каноническими.
- Английские страницы обновляются вручную, когда изменение важно для
  англоязычных пользователей.
- Имена API, команды, JSON-ключи, параметры, имена файлов, URL и примеры кода
  не переводятся, если само API не использует локализованные значения.

## Структура каталогов

Документация организована как параллельные языковые деревья внутри каждого
устройства:

```text
source/
  AZ/
    ru/
      index.rst
      commands_ru.rst
    en/
      index.rst
      commands.rst
```

Эту структуру нужно сохранять для новой документации по устройствам. Текущее
соглашение допускает русские файлы с суффиксом `_ru.rst`, а английские файлы
либо без языкового суффикса (`commands.rst`), либо с существующим суффиксом
`_en.rst`.

Предпочтительное именование для новых страниц:

```text
ru/page_ru.rst
en/page.rst
```

## Переключатель языка

Переключатель языка выводится в левом верхнем блоке сайта через шаблон
`source/_templates/sidebar/brand.html`. Логика поиска парной страницы находится
в `source/conf.py`.

Не добавляйте ручные ссылки `English version` / `Русская версия` внутрь
страниц: это приведет к дублю переключателя.

## Проверка парности страниц

Перед публикацией, а также после добавления или удаления страниц, запускайте:

```bash
python tools/check_translations.py
```

В Windows, если `python` недоступен в `PATH`, используйте:

```bat
py -3 tools\check_translations.py
```

Проверка сравнивает пары страниц внутри каждого каталога `source/<device>/ru`
и `source/<device>/en`. Суффиксы `_ru` и `_en` нормализуются, поэтому
`commands_ru.rst` соответствует как `commands.rst`, так и `commands_en.rst`.
